# DESS-Calc · 甲烷重整制氢 + 燃料电池热电联供 测算工具

纯前端、单页、**可离线运行**的工程测算小工具：输入机组参数 → 自动算出**氢耗、甲烷耗、产水量、余热热水量、CO₂ 排放、单位电成本**。

- 🌐 在线版（GitHub Pages）：https://jeeftang.github.io/DESS-Calc/
- 📦 离线版：直接双击 `index.html` 即可（无需联网、无需后端、无外部 CDN）
- 📱 移动端自适应，手机上打开可正常使用

> 用途：获客引流（挂到节能测算站）+ 方案报价快速出数。

---

## 一、功能

**输入（A–E 五组）**

| 组 | 参数 |
|---|---|
| A 机组 | 电功率 P (kW)、发电效率 η (%)、年运行小时 h |
| B 燃料 | 甲烷电/气比 r (kW/Nm³)、PSA 氢回收率、重整转化率 |
| C 产水 | 产水回收率 (%)、水碳比 S/C |
| D 余热 | ① 可用余热功率 Q (kW) 或 ② 蒸汽流量 (t/h) + 蒸汽温度（默认 600℃）；进水温度、出水温度、换热效率 |
| E 价格 | 甲烷 (元/Nm³)、电 (元/kWh)、水 (元/m³)、热 (元/GJ) |

**输出**

- 核心指标：氢耗 (kg/h、Nm³/h)、甲烷耗 (Nm³/h、kg/h)、全链路效率（**>50% 显红警示**）、理论反推甲烷耗
- 水账：理论产水、实际回收产水、产水率、重整配汽需求、净补水
- 余热：可用余热功率、有效热、热水产量（理论/实际）、可供热功率
- 碳排放：CO₂ kg/h、年排放 t、单位电 CO₂
- 经济性：年发电量、年耗气量/气费、年净补水量/水费、年热水产量、年可供热量、热水收益、**单位电成本**（含/不含热收益抵扣）
- 校验行：理论反推对比、氢耗体积校核、水账校核、热平衡校核
- **反算模式（可选）**：按目标电功率、或按目标热水产量反推所需的氢/甲烷/余热/蒸汽
- 「复制结果文本」按钮 · 「打印/存 PDF」按钮

## 二、算法公式与口径

### 常数（口径锁定，不要改）

| 常数 | 取值 | 说明 |
|---|---|---|
| 氢低位热值 `LHV_H2` | 33.3 kWh/kg | |
| 氢标况密度 `ρ_H2` | 0.0899 kg/Nm³ | |
| 甲烷标况密度 `ρ_CH4` | 0.717 kg/Nm³ | |
| 甲烷低位热值 `LHV_CH4` | 9.94 kWh/Nm³ | = 35.8 MJ/Nm³ |
| 水比热 `c_w` | 4.18 kJ/(kg·K) | |
| 化学计量 | 1 kg H₂ → 9 kg H₂O | H₂ + ½O₂ → H₂O |
| 碳排因子 | 1 Nm³ CH₄ → 1.964 kg CO₂ | |
| 600℃ 蒸汽冷至 50℃ 总放热 | 3516 kJ/kg | 显热 1050 + 潜热 2257 + 显热 209 |

### 公式

```
① 氢耗        m_H2  = P / (η × 33.3)            [kg/h]
              V_H2  = m_H2 / 0.0899              [Nm³/h]

② 甲烷耗      V_CH4 = P / r                      [Nm³/h]
              m_CH4 = V_CH4 × 0.717              [kg/h]
   全链路效率 η_all = P / (V_CH4 × 9.94)          → 若 > 0.50 显示警示
   理论反推（校验行）V_CH4_theory = m_H2 × 2 ÷ 0.717 ÷ η_PSA(0.8) ÷ η_ref(0.9)

③ 产水        理论 m_H2O = m_H2 × 9              [kg/h]
              实际 = 理论 × 回收率                [L/h]
              产水率 = 理论 ÷ P                   [kg/kWh]

④ 重整配汽    蒸汽 = (V_CH4 ÷ 22.414) × S/C × 18  [kg/h]（参考行，用于算净水账）

⑤ 余热热水    若输入是热功率：Q_用 = Q × η_hex
              若输入是蒸汽：Q = m_steam(t/h) × 3516 kJ/kg ÷ 3.6   → kW
              V_热水 = Q_用 × 3600 ÷ (4.18 × (T_out − T_in)) ÷ 1000   [m³/h]

⑥ CO₂        m_CO2 = V_CH4 × 1.964               [kg/h]
              年排放 = m_CO2 × h ÷ 1000           [t]

⑦ 经济性      年发电 MWh = P × h ÷ 1000
              年耗气 = V_CH4 × h [Nm³]，年气费 = 年耗气 × 气价
              年净补水 = max(0, ④蒸汽需求 − ③回收产水) [kg/h] → × h ÷ 1000 [m³/年]
              年可供热量 = V_热水(t/h) × 4.18 × ΔT ÷ 1000 [GJ/h] × h
              单位电成本 = (年气费 + 年水费) ÷ (年发电 kWh)
```

### 默认参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 电功率 P | 100 kW | |
| 发电效率 η | 50% | 可调 40%~60%（整机净输出，按氢 LHV 计） |
| 年运行小时 h | 8000 | |
| 甲烷电/气比 r | 5 kW/Nm³ | ⚠️ **老唐实测经验值，待复核**，UI 已标注 |
| 产水回收率 | 80% | 冷凝回收，范围 70%~90% |
| 水碳比 S/C | 5 | 参考值 |
| 进水温度 | 15℃ | 冬季可调低 |
| 出水温度 | 50℃ | |
| 换热效率 η_hex | 0.75 | 0.70~0.85 |
| PSA 回收率 | 0.80 | 仅用于理论反推行 |
| 重整转化率 | 0.90 | 仅用于理论反推行 |
| 甲烷价 | 3.20 元/Nm³ | 示例值，可改 |
| 电价 | 0.64 元/kWh | 示例值，可改 |
| 水价 | 4.00 元/m³ | 示例值，可改 |
| 热价 | 60 元/GJ | 示例值，可改 |

### ⚠️ 两条必须知道的口径提醒

1. **全链路效率警示**：`r = 5 kW/Nm³` 意味着全链路效率 50.3%，与「电堆 50% + 重整 0.9 + PSA 0.8（理论 30~38%）」存在张力。→ 结果区显示小字提示：*该气电比偏低（乐观），请确认是否已扣除重整自用甲烷、PSA 尾气是否回烧*。
2. **系统是净耗水的**：重整配汽量（④）通常大于 FC 产水量（③），水账按「补水」看，**不要**按「产水外供」讲。

## 三、自测校验表（默认参数下）

以 **P=100 kW、η=50%、r=5 kW/Nm³、回收率 0.8、Q=100 kW、η_hex=0.75、15→50℃** 为例：

| 项目 | 期望值 | 实测（本工具） |
|---|---|---|
| 氢耗 | 6.01 kg/h ≈ 67 Nm³/h | ✅ 6.0060 kg/h / 66.8076 Nm³/h |
| 甲烷耗 | 20 Nm³/h ≈ 14.34 kg/h | ✅ 20.0000 Nm³/h / 14.3400 kg/h |
| 全链路效率 | 50.3%（触发警示） | ✅ 50.3018% |
| 理论产水 | 54.1 kg/h | ✅ 54.0541 kg/h |
| 回收产水 | ≈ 43 L/h | ✅ 43.2432 L/h |
| 产水率 | 0.54 kg/kWh | ✅ 0.5405 kg/kWh |
| CO₂ | 39.3 kg/h；年 ≈ 314 t | ✅ 39.2800 kg/h / 314.2400 t |
| 余热热水（Q=100kW） | 理论 2.46 → 实际 ≈ 1.85 m³/h | ✅ 2.4607 / 1.8455 m³/h |
| 蒸汽 1 t/h（600℃→50℃） | ≈ 18 m³/h 50℃ 热水 | ✅ 18.0246 m³/h |

**复跑自测**（需要 Node.js）：

```bash
node selfcheck.js
```

脚本会从 `index.html` 中抽取计算核心（`==CALC-CORE-START/END==` 区块）后执行，**测的就是页面里跑的那份逻辑**，避免两份代码不同步。

## 五、免责说明

- 本工具为**工程估算参考**，结果受气电比 `r`、回收率、换热效率等参数假设影响较大。
- **甲烷电/气比 r 默认 5 kW/Nm³ 为经验值，尚待实测复核**；正式报价与合同请以实测数据、厂家样本与项目实测报告为准。
- CO₂ 排放按甲烷碳含量折算，若氢源为生物甲烷/绿氢，应标注「生物源碳」另行核算。
- 本页为纯静态页面，**不采集任何数据、不连接任何后端**。
