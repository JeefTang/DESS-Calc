# DESS-Calc · 甲烷重整制氢 + 燃料电池热电联供 测算工具

纯前端、单页、**可离线运行**的工程测算小工具：输入机组参数 → 自动算出**氢耗、甲烷耗、产水量、余热热水量、CO₂ 排放、单位电成本**。

- 🌐 在线版（GitHub Pages）：https://jeeftang.github.io/DESS-Calc/
- 📦 离线版：直接双击 `index.html` 即可（无需联网、无需后端、无外部 CDN）
- 📱 移动端自适应，手机上打开可正常使用

> 用途：获客引流（挂到节能测算站）+ 方案报价快速出数。

---

## 一、功能

**输入（A–E 五组）**

| 组 | 参数 |
|---|---|
| A 机组 | 电功率 P (kW)、发电效率 η (%)、年运行小时 h |
| B 燃料 | 甲烷电/气比 r (kW/Nm³)、PSA 氢回收率、重整转化率 |
| C 产水/重整配气 | 产水回收率 (%)、水碳比 S/C、**重整器加热方式（内置燃烧器·协议 / 催化部分氧化）**、**氧碳比 O₂/C**（仅 CPO）、**沼气 CH₄ 含量 (%)**、**重整供热方式（自热耦合 / 外供蒸汽）**、自产蒸汽占比 (%) |
| D 余热 | ① 可用余热功率 Q (kW) 或 ② 蒸汽流量 (t/h) + 蒸汽温度（默认 600℃）；进水温度、出水温度、换热效率 |
| E 价格 | 甲烷 (元/Nm³)、电 (元/kWh)、水 (元/m³)、热 (元/GJ) |
| **F 投资与效益** | **设备投资（含税·含前处理，默认 195 万元）**、年运维费率、寿命期、折现率、年补贴 |
| G 反算（可选） | 按目标电功率 / 按目标热水产量反推 |

**输出**

- 核心指标：氢耗 (kg/h、Nm³/h)、甲烷耗 (Nm³/h、kg/h)、全链路效率（**>50% 显红警示**）、理论反推甲烷耗
- **重整配气**：重整蒸汽需求、其中自产蒸汽 / 需外供蒸汽、重整器加热方式、O₂ 配入量、空气量、空气带入 N₂、沼气 CH₄ 含量、**变换气·干基 H₂、脱氮后·干基 H₂、进堆氢浓度（参考）**
- 水账：理论产水、实际回收产水、产水率、净补水
- 余热：可用余热功率、有效热、热水产量（理论/实际）、可供热功率
- 碳排放：CO₂ kg/h、年排放 t、单位电 CO₂
- 经济性：年发电量、年耗气量/气费、年净补水量/水费、年热水产量、年可供热量、热水收益、**单位电成本**（含/不含热收益抵扣）
- **经济效益（投资与回报）**：年发电收益、年供热收益、年运行成本、**年净收益**、**静态回收期**、**动态回收期**、**ROI**、**NPV**、**IRR**、寿命期累计净收益；以及**敏感性表**（气价 × 电价 → 回收期）
- 校验行：理论反推对比、氢耗体积校核、水账校核、热平衡校核
- **反算模式（可选）**：按目标电功率、或按目标热水产量反推所需的氢/甲烷/余热/蒸汽
- 「复制结果文本」按钮 · 「打印/存 PDF」按钮

## 二、算法公式与口径

### 常数（口径锁定，不要改）

| 常数 | 取值 | 说明 |
|---|---|---|
| 氢低位热值 `LHV_H2` | 33.3 kWh/kg | |
| 氢标况密度 `ρ_H2` | 0.0899 kg/Nm³ | |
| 甲烷标况密度 `ρ_CH4` | 0.717 kg/Nm³ | |
| 甲烷低位热值 `LHV_CH4` | 9.94 kWh/Nm³ | = 35.8 MJ/Nm³ |
| 水比热 `c_w` | 4.18 kJ/(kg·K) | |
| 化学计量 | 1 kg H₂ → 9 kg H₂O | H₂ + ½O₂ → H₂O |
| 碳排因子 | 1 Nm³ CH₄ → 1.964 kg CO₂ | |
| 600℃ 蒸汽冷至 50℃ 总放热 | 3516 kJ/kg | 显热 1050 + 潜热 2257 + 显热 209 |

### 公式

```
① 氢耗        m_H2  = P / (η × 33.3)            [kg/h]
              V_H2  = m_H2 / 0.0899              [Nm³/h]

② 甲烷耗      V_CH4 = P / r                      [Nm³/h]
              m_CH4 = V_CH4 × 0.717              [kg/h]
   全链路效率 η_all = P / (V_CH4 × 9.94)          → 若 > 0.50 显示警示
   理论反推（校验行）V_CH4_theory = m_H2 × 2 ÷ 0.717 ÷ η_PSA(0.8) ÷ η_ref(0.9)

③ 产水        理论 m_H2O = m_H2 × 9              [kg/h]
              实际 = 理论 × 回收率                [L/h]
              产水率 = 理论 ÷ P                   [kg/kWh]

④ 重整配气    蒸汽需求 = (V_CH4 ÷ 22.414) × S/C × 18   [kg/h]
              自热耦合（默认）：自产蒸汽 = 需求 × 自产占比（默认 100%）→ 不外供蒸汽
              外供蒸汽模式：自产 = 0，全部外供
              需外供蒸汽 = 蒸汽需求 − 自产蒸汽

④b 重整器加热  内置燃烧器（协议默认）：燃料气+空气→燃烧器，间接加热；空气不进工艺气（N₂=0）
              催化部分氧化（对比）：空气配入催化床供热；N₂ 随工艺气稀释富氢
              O₂ 需求 = V_CH4 × (O₂/C)；空气量 = O₂ ÷ 0.21；带入 N₂ = 空气 × 0.79（仅 CPO）
              O₂/C 默认 0.40 ⚠️ 热中性估算，待工艺包确认（仅 CPO 模式用）

④c 进堆氢浓度  化学计量氢 = V_CH4 × 4（内置燃烧器·纯蒸汽重整）
                或 V_CH4 × (4 − 2·O₂/C)（CPO：部分 CH₄ 每分子只得 3 H₂）
              CO₂ = V_CH4 × (1 + (1−ch4f)/ch4f)   ← 甲烷转化的碳 + 沼气自带 CO₂
              纯化前干基 H₂ = H₂ ÷ (H₂ + CO₂ + N₂)   ← N₂ 仅 CPO 配空气时非零
              脱氮后干基 H₂ = H₂ ÷ (H₂ + CO₂)         ← 仅脱 N₂（CO₂ 未脱）
              协议要求：进堆 H₂ ≥ 70%（体积）、CO < 10 ppm

⑤ 余热热水    若输入是热功率：Q_用 = Q × η_hex
              若输入是蒸汽：Q = m_steam(t/h) × 3516 kJ/kg ÷ 3.6   → kW
              V_热水 = Q_用 × 3600 ÷ (4.18 × (T_out − T_in)) ÷ 1000   [m³/h]

⑥ CO₂        m_CO2 = V_CH4 × 1.964               [kg/h]
              年排放 = m_CO2 × h ÷ 1000           [t]

⑦ 经济性      年发电 MWh = P × h ÷ 1000
              年耗气 = V_CH4 × h [Nm³]，年气费 = 年耗气 × 气价
              年净补水 = max(0, ④需外供蒸汽 − ③回收产水) [kg/h] → × h ÷ 1000 [m³/年]
              年可供热量 = V_热水(t/h) × 4.18 × ΔT ÷ 1000 [GJ/h] × h
              单位电成本 = (年气费 + 年水费) ÷ (年发电 kWh)

⑧ 经济效益    投资 I = 172.57 万元（不含税 · 含前处理；合同含税 195 万）
              年发电收益 = 年发电 MWh × 1000 × 电价
              年供热收益 = 年可供热量 GJ × 热价
              年运维费   = I × 运维费率（默认 2%/年，假设值）
              年净收益   = 年发电收益 + 年供热收益 + 年补贴 − 年气费 − 年水费 − 年运维费
              静态回收期 = I ÷ 年净收益
              ROI       = 年净收益 ÷ I
              NPV       = Σ 年净收益 ÷ (1+折现率)^y − I        (y = 1..寿命期)
              动态回收期 = 累计折现现金流转正的时点（线性内插）
              IRR       = 使 NPV = 0 的折现率（二分法）
```

### ⚠️ 两条必须知道的口径提醒

1. **全链路效率警示**：`r = 5 kW/Nm³` 意味着全链路效率 50.3%，与「电堆 50% + 重整 0.9 + PSA 0.8（理论 30~38%）」存在张力。→ 结果区显示小字提示：*该气电比偏低（乐观），请确认是否已扣除重整自用甲烷、PSA 尾气是否回烧*。
2. **重整用汽口径（2026-10-15 修正）**：本工艺为**自热耦合**——反应器自热，**不需外通蒸汽**；重整用汽由反应过程自产（部分燃料氧化/变换产汽 + 系统水热回收）。
   - 默认「自热耦合 · 自产 100%」→ 需外供蒸汽 = 0 → 净补水 = 0（**系统水自平衡**，无需外部补充水）。
   - 工具保留「外供蒸汽（外部锅炉）」对比模式：此时净补水 = 配汽量 − 回收产水（默认参数下 ≈ 37 kg/h），水账按「补充水」看。
3. **重整器加热方式以技术协议为准（2026-10-15 老唐定）**：协议 3.2.2 明确「重整反应器**内置燃烧器**，燃烧部分燃料气提供反应热」→ **空气仅供燃烧器助燃，不进工艺气**（燃烧烟气单独排放）。工具默认即此口径；另保留**催化部分氧化（配空气入床）** 作为对比模式（该模式下空气带入 N₂ 会稀释富氢气）。
4. **进堆氢浓度（参考值）：≈ 70~74%**（2026-10-15 老唐要求补充）
   - 技术协议要求：**产品（进堆）氢 ≥ 70%（体积分数），CO < 10 ppm**
   - 内置燃烧器口径（默认，V_CH4=20、沼气 CH₄=60%、全转化）：化学计量 H₂ = 80 Nm³/h；变换气**干基 H₂ ≈ 70.6%**（稀释主要来自**沼气自带 CO₂**，工艺气无 N₂）→ 纯化脱除 CO₂/CO/CH₄ 后进堆 **≥70%** ✓
   - 沼气 CH₄=50%（协议下限）→ 干基 H₂ ≈ **66.7%**；CH₄=70% → ≈ **73.7%** → **对应协议「≥70%」的合理区间**
   - 对照：协议设备清单含「**吸附塔（脱氮）**」+ 纯化尾气含 N₂ → 说明**工艺气确实含 N₂**（来源为原料气/工艺引入，待工艺包确认）；该塔负责把 N₂ 脱除至进堆限值
   - 催化部分氧化对比口径（空气 O₂/C=0.40）：N₂ 稀释更强，纯化前干基 H₂ 仅 ≈ 50%，需靠脱氮回升
   - 趋势：**沼气 CH₄ ↑ → 氢浓度 ↑**；O₂/C ↑ → 氢浓度 ↓；与主口径氢耗（6 kg/h）自洽的 O₂/C ≈ 0.33

## 三·补、经济效益口径（2026-10-15 老唐确认）

**投资口径**：整套装置 **不含税 172.57 万元（含前处理）**；合同含税 195.00 万元（税率 13%，税额 22.43 万），按不含税价计入项目投入。

**收益 = 年发电收益 + 年供热收益 + 补贴**
- 年发电收益 = 年发电量 × 电价（自用场景＝替代外购电；上网场景填上网电价）
- 年供热收益 = 年可供热量 × 热价

**成本 = 年气费 + 年水费 + 年运维费**
- 年运维费 = 投资额 × 运维费率（默认 2%/年，含人工/耗材/大修 —— **任务书未给，为假设值**）

**其余参数（老唐确认）**：寿命期 10 年、折现率 6%、发电按 0.70 元/kWh；不计年衰减、不计通胀与所得税。
