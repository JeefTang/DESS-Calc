# DESS-Calc · 分布式供能系统 测算工具（甲烷/天然气 重整制氢 + 燃料电池热电联供）

纯前端、**可离线运行**的工程测算工具，含**两个模块**：

| 模块 | 入口 | 定位 |
|---|---|---|
| **工业版**（百千瓦级 · 协议口径） | `index.html` | 沼气/天然气重整制氢 + 燃料电池热电联供，工业级机组参数 → 氢耗/甲烷耗/产水/余热/碳排/单位成本/经济效益 |
| **民用版**（别墅 / 城镇自建房） | `residential.html` | **天然气/液化气 重整制氢热电联供**：供暖 + 洗浴热负荷、补水量、家用电器模块匹配、**可选屋顶光伏**、**与燃气热水器经济对比** |

- 🌐 在线版（GitHub Pages）：https://jeeftang.github.io/DESS-Calc/ ｜ 民用版：https://jeeftang.github.io/DESS-Calc/residential.html
- 📦 离线版：直接双击 `index.html` / `residential.html` 即可（无需联网、无需后端、无外部 CDN）
- 📱 移动端自适应，手机上打开可正常使用

> 用途：获客引流（挂到节能测算站）+ 方案报价快速出数。

## 一、功能

**输入（A–H 八组）**

| 组 | 参数 |
|---|---|
| A 机组 | 电功率 P (kW)、发电效率 η (%)、年运行小时 h |
| B 燃料 | 甲烷电/气比 r (kW/Nm³)、PSA 氢回收率、重整转化率 |
| C 产水/重整配气 | 产水回收率 (%)、水碳比 S/C、**重整器加热方式（内置燃烧器·协议 / 催化部分氧化）**、**氧碳比 O₂/C**（仅 CPO）、**沼气 CH₄ 含量 (%)**、**重整供热方式（自热耦合 / 外供蒸汽）**、自产蒸汽占比 (%) |
| D 余热 | ① 可用余热功率 Q (kW) 或 ② 蒸汽流量 (t/h) + 蒸汽温度（默认 600℃）；进水温度、出水温度、换热效率 |
| E 价格 | 甲烷 (元/Nm³)、电 (元/kWh)、水 (元/m³)、热 (元/GJ) |
| **F 投资与效益** | **设备投资（含税·含前处理，默认 195 万元）**、年运维费率、寿命期、折现率、年补贴 |
| **G 气源与碳资产**（2026-10-15 新增） | **气源类型（养殖场沼气 / 油田伴生气 / 煤矿瓦斯（井下抽采）/ 煤层气（地面抽采）/ 自定义）**、基准线（直排放空 / 火炬燃烧 / 无）、火炬燃烧效率、**甲烷 GWP（100 年 28 / 20 年 84）**、碳属性（生物源 / 化石源）、电网排放因子、是否计入「替代电网」减排、碳价、碳资产计入期、碳收益是否计入经济评价 |
| H 反算（可选） | 按目标电功率 / 按目标热水产量反推 |

**输出**

- 核心指标：氢耗 (kg/h、Nm³/h)、甲烷耗 (Nm³/h、kg/h)、全链路效率（**>50% 显红警示**）、理论反推甲烷耗
- **重整配气**：重整蒸汽需求、其中自产蒸汽 / 需外供蒸汽、重整器加热方式、O₂ 配入量、空气量、空气带入 N₂、沼气 CH₄ 含量、**变换气·干基 H₂、脱氮后·干基 H₂、进堆氢浓度（参考）**
- 水账：理论产水、实际回收产水、产水率、净补水
- 余热：可用余热功率、有效热、热水产量（理论/实际）、可供热功率
- 碳排放：CO₂ kg/h、年排放 t、单位电 CO₂
- **碳资产（新增）**：**年减排量 (tCO₂e/年)、减排强度 (kgCO₂e/kWh)、年碳收益 (万元)、计入期累计减排、碳资产现值（折现）、碳收益占年收益比**；以及**减排量拆解三行**（① 基准线排放 + ② 替代电网电量减排 − ③ 项目排放）；气源自适应**适配度提示**（含技术红线）
- 经济性：年发电量、年耗气量/气费、年净补水量/水费、年热水产量、年可供热量、热水收益、**单位电成本**（含/不含热收益抵扣）
- **经济效益（投资与回报）**：年发电收益、年供热收益、年运行成本、**年净收益**、**静态回收期**、**动态回收期**、**ROI**、**NPV**、**IRR**、寿命期累计净收益；以及**敏感性表**（气价 × 电价 → 回收期）
- 校验行：理论反推对比、氢耗体积校核、水账校核、热平衡校核
- **反算模式（可选）**：按目标电功率、或按目标热水产量反推所需的氢/甲烷/余热/蒸汽
- 「复制结果文本」按钮 · 「打印/存 PDF」按钮

## 二、算法公式与口径

### 常数（口径锁定，不要改）

| 常数 | 取值 | 说明 |
|---|---|---|
| 氢低位热值 `LHV_H2` | 33.3 kWh/kg | |
| 氢标况密度 `ρ_H2` | 0.0899 kg/Nm³ | |
| 甲烷标况密度 `ρ_CH4` | 0.717 kg/Nm³ | |
| 甲烷低位热值 `LHV_CH4` | 9.94 kWh/Nm³ | = 35.8 MJ/Nm³ |
| 水比热 `c_w` | 4.18 kJ/(kg·K) | |
| 化学计量 | 1 kg H₂ → 9 kg H₂O | H₂ + ½O₂ → H₂O |
| 碳排因子 | 1 Nm³ CH₄ → 1.964 kg CO₂ | |
| 600℃ 蒸汽冷至 50℃ 总放热 | 3516 kJ/kg | 显热 1050 + 潜热 2257 + 显热 209 |

### 公式

```
① 氢耗        m_H2  = P / (η × 33.3)            [kg/h]
              V_H2  = m_H2 / 0.0899              [Nm³/h]

② 甲烷耗      V_CH4 = P / r                      [Nm³/h]
              m_CH4 = V_CH4 × 0.717              [kg/h]
   全链路效率 η_all = P / (V_CH4 × 9.94)          → 若 > 0.50 显示警示
   理论反推（校验行）V_CH4_theory = m_H2 × 2 ÷ 0.717 ÷ η_PSA(0.8) ÷ η_ref(0.9)

③ 产水        理论 m_H2O = m_H2 × 9              [kg/h]
              实际 = 理论 × 回收率                [L/h]
              产水率 = 理论 ÷ P                   [kg/kWh]

④ 重整配气    蒸汽需求 = (V_CH4 ÷ 22.414) × S/C × 18   [kg/h]
              自热耦合（默认）：自产蒸汽 = 需求 × 自产占比（默认 100%）→ 不外供蒸汽
              外供蒸汽模式：自产 = 0，全部外供
              需外供蒸汽 = 蒸汽需求 − 自产蒸汽

④b 重整器加热  内置燃烧器（协议默认）：燃料气+空气→燃烧器，间接加热；空气不进工艺气（N₂=0）
              催化部分氧化（对比）：空气配入催化床供热；N₂ 随工艺气稀释富氢
              O₂ 需求 = V_CH4 × (O₂/C)；空气量 = O₂ ÷ 0.21；带入 N₂ = 空气 × 0.79（仅 CPO）
              O₂/C 默认 0.40 ⚠️ 热中性估算，待工艺包确认（仅 CPO 模式用）

④c 进堆氢浓度  化学计量氢 = V_CH4 × 4（内置燃烧器·纯蒸汽重整）
                或 V_CH4 × (4 − 2·O₂/C)（CPO：部分 CH₄ 每分子只得 3 H₂）
              CO₂ = V_CH4 × (1 + (1−ch4f)/ch4f)   ← 甲烷转化的碳 + 沼气自带 CO₂
              纯化前干基 H₂ = H₂ ÷ (H₂ + CO₂ + N₂)   ← N₂ 仅 CPO 配空气时非零
              脱氮后干基 H₂ = H₂ ÷ (H₂ + CO₂)         ← 仅脱 N₂（CO₂ 未脱）
              协议要求：进堆 H₂ ≥ 70%（体积）、CO < 10 ppm

⑤ 余热热水    若输入是热功率：Q_用 = Q × η_hex
              若输入是蒸汽：Q = m_steam(t/h) × 3516 kJ/kg ÷ 3.6   → kW
              V_热水 = Q_用 × 3600 ÷ (4.18 × (T_out − T_in)) ÷ 1000   [m³/h]

⑥ CO₂        m_CO2 = V_CH4 × 1.964               [kg/h]
              年排放 = m_CO2 × h ÷ 1000           [t]

⑦ 经济性      年发电 MWh = P × h ÷ 1000
              年耗气 = V_CH4 × h [Nm³]，年气费 = 年耗气 × 气价
              年净补水 = max(0, ④需外供蒸汽 − ③回收产水) [kg/h] → × h ÷ 1000 [m³/年]
              年可供热量 = V_热水(t/h) × 4.18 × ΔT ÷ 1000 [GJ/h] × h
              单位电成本 = (年气费 + 年水费) ÷ (年发电 kWh)

⑧ 经济效益    投资 I = 172.57 万元（不含税 · 含前处理；合同含税 195 万）
              年发电收益 = 年发电 MWh × 1000 × 电价
              年供热收益 = 年可供热量 GJ × 热价
              年运维费   = I × 运维费率（默认 2%/年，假设值）
              年净收益   = 年发电收益 + 年供热收益 + 年补贴 + 年碳收益 − 年气费 − 年水费 − 年运维费
              静态回收期 = I ÷ 年净收益
              ROI       = 年净收益 ÷ I
              NPV       = Σ 年净收益 ÷ (1+折现率)^y − I        (y = 1..寿命期)
              动态回收期 = 累计折现现金流转正的时点（线性内插）
              IRR       = 使 NPV = 0 的折现率（二分法）

⑨ 碳资产（2026-10-15 新增）
              CH4_t      = V_CH4 × 0.717 ÷ 1000            [t/h] 甲烷质量流量
              co2FromCH4 = V_CH4 × 1.964 ÷ 1000            [tCO₂/h] 甲烷碳完全氧化
             基准线排放（视项目前原料气处置方式）：
               直排放空   BE = CH4_t × GWP
               火炬燃烧   BE = co2FromCH4 × η_flare + CH4_t × (1−η_flare) × GWP
               无（已利用）BE = 0
             项目排放     PE = co2FromCH4（化石源）| 0（生物源·短周期碳）
             替代电网     GA = P × EF_grid ÷ 1000           [tCO₂e/h]（EF 默认 0.5568 t/MWh）
             年减排量     ER = (BE + GA − PE) × h            [tCO₂e/年]
             减排强度     = ER × 1000 ÷ (P × h)             [kgCO₂e/kWh]
             年碳收益     = ER × 碳价
             计入期累计   = ER × 计入期
             碳资产现值   = Σ 年碳收益 ÷ (1+折现率)^y         (y = 1..计入期)
             ⚠ 碳收益是否计入经济评价：开关控制（默认计入）
```

### ⚠️ 两条必须知道的口径提醒

1. **全链路效率警示**：`r = 5 kW/Nm³` 意味着全链路效率 50.3%，与「电堆 50% + 重整 0.9 + PSA 0.8（理论 30~38%）」存在张力。→ 结果区显示小字提示：*该气电比偏低（乐观），请确认是否已扣除重整自用甲烷、PSA 尾气是否回烧*。
2. **重整用汽口径（2026-10-15 修正）**：本工艺为**自热耦合**——反应器自热，**不需外通蒸汽**；重整用汽由反应过程自产（部分燃料氧化/变换产汽 + 系统水热回收）。
   - 默认「自热耦合 · 自产 100%」→ 需外供蒸汽 = 0 → 净补水 = 0（**系统水自平衡**，无需外部补充水）。
   - 工具保留「外供蒸汽（外部锅炉）」对比模式：此时净补水 = 配汽量 − 回收产水（默认参数下 ≈ 37 kg/h），水账按「补充水」看。
3. **重整器加热方式以技术协议为准（2026-10-15 老唐定）**：协议 3.2.2 明确「重整反应器**内置燃烧器**，燃烧部分燃料气提供反应热」→ **空气仅供燃烧器助燃，不进工艺气**（燃烧烟气单独排放）。工具默认即此口径；另保留**催化部分氧化（配空气入床）** 作为对比模式（该模式下空气带入 N₂ 会稀释富氢气）。
4. **进堆氢浓度（参考值）：≈ 70~74%**（2026-10-15 老唐要求补充）
   - 技术协议要求：**产品（进堆）氢 ≥ 70%（体积分数），CO < 10 ppm**
   - 内置燃烧器口径（默认，V_CH4=20、沼气 CH₄=60%、全转化）：化学计量 H₂ = 80 Nm³/h；变换气**干基 H₂ ≈ 70.6%**（稀释主要来自**沼气自带 CO₂**，工艺气无 N₂）→ 纯化脱除 CO₂/CO/CH₄ 后进堆 **≥70%** ✓
   - 沼气 CH₄=50%（协议下限）→ 干基 H₂ ≈ **66.7%**；CH₄=70% → ≈ **73.7%** → **对应协议「≥70%」的合理区间**
   - 对照：协议设备清单含「**吸附塔（脱氮）**」+ 纯化尾气含 N₂ → 说明**工艺气确实含 N₂**（来源为原料气/工艺引入，待工艺包确认）；该塔负责把 N₂ 脱除至进堆限值
   - 催化部分氧化对比口径（空气 O₂/C=0.40）：N₂ 稀释更强，纯化前干基 H₂ 仅 ≈ 50%，需靠脱氮回升
   - 趋势：**沼气 CH₄ ↑ → 氢浓度 ↑**；O₂/C ↑ → 氢浓度 ↓；与主口径氢耗（6 kg/h）自洽的 O₂/C ≈ 0.33

## 三·补、经济效益口径（2026-10-15 老唐确认）

**投资口径**：整套装置 **不含税 172.57 万元（含前处理）**；合同含税 195.00 万元（税率 13%，税额 22.43 万），按不含税价计入项目投入。

**收益 = 年发电收益 + 年供热收益 + 补贴 + 年碳收益（新增）**
- 年发电收益 = 年发电量 × 电价（自用场景＝替代外购电；上网场景填上网电价）
- 年供热收益 = 年可供热量 × 热价
- **年碳收益 = 年减排量 × 碳价**（可选开关，默认计入）

**成本 = 年气费 + 年水费 + 年运维费**
- 年运维费 = 投资额 × 运维费率（默认 2%/年，含人工/耗材/大修 —— **任务书未给，为假设值**）

## 三·二、碳资产经济模型（2026-10-15 新增）

**建模思路**：项目把原本**直排放空 / 火炬燃烧**的含甲烷气体转化为电 + 热，碳资产 = 「避免的甲烷排放」+「替代电网电量」−「项目自身排放」。

### 两种收支口径

| 类别 | 公式 | 说明 |
|---|---|---|
| ① 基准线排放 | 直排：`CH4_t × GWP`；火炬：`co2FromCH4 × η_flare + CH4_t × (1−η_flare) × GWP`；无：0 | 项目未实施时原料气的处置排放 |
| ② 替代电网 | `P × EF_grid ÷ 1000`（tCO₂e/h）| 机组发电替代外购电网电量；可关闭 |
| ③ 项目排放 | `co2FromCH4`（化石源）/ `0`（生物源）| 甲烷碳氧化为 CO₂；生物源按短周期碳计 0 |
| **净减排 ER** | `(① + ② − ③) × h` | tCO₂e/年 |
| 其它 | 减排强度 `ER×1000÷(P×h)`；年碳收益 `ER × 碳价`；计入期累计 `ER × 计入期`；碳资产现值 `Σ 碳收益 ÷ (1+折现率)^y` | |

### 三种气源的控制差异（同机组 P=100kW 下的实测值）

| 气源 | 预设 CH₄ | 预设基准线 | 碳属性 | 净减排 tCO₂e/年 | 年碳收益 | 建议 |
|---|---|---|---|---|---|---|
| **养殖场沼气** | 60% | 直排放空 | 生物源 | **3,657.6** | 25.60 万元 | ✅ **主战场**：H₂S 1000~4000ppm → 脱硫是工艺护城河；余热回用发酵罐 |
| **油田伴生气** | 85% | 火炬燃烧 | 化石源 | 503.4 | 3.52 万元 | ✅ 可做：重烃 C₂+ 需预转化/脱重烃；三桶油准入门槛高 |
| **煤层气（地面）** | 92% | 直排放空 | 化石源 | 3,343~3,658* | — | 🔶 技术可行（无空气）；但常有管道/液化出路 |
| **煤矿瓦斯（井下）** | 45% | 直排放空 | 化石源 | 3,343.4 | 23.40 万元 | ⚠️ **不建议**：混空气 O₂ 5~15% → 烧催化剂/触红线，需先提浓 |

\* 煤层气默认 CH₄=92%，与沼气同为直排+化石源，但生物源/化石源差异使净减排略低。

> ⚠️ **GWP 口径对结果影响极大**：默认 GWP₁₀₀=28；若切 **GWP₂₀=84**，默认工况净减排 3,657.6 → **10,081.9 tCO₂e/年**（碳收益 70.6 万元）。CCER/VCS 备案请按方法学指定值。

### 适配度判断（技术红线 · 摘自三气源速查）

- **一票否决三条**：① 含 **O₂**（煤矿瓦斯死穴）② 重烃 **C₂+**（油田伴生气要防结焦）③ **H₂S / 硅氧烷**（沼气必查）

## 六·一、民用版模块（`residential.html`）

**定位**：面向高端别墅 / 城镇自建房，测算「天然气重整制氢热电联供」家用装置的发电+供热能力，并与**燃气热水器**做经济对比。

**输入（R1–R7）**

| 组 | 参数 |
|---|---|
| R1 建筑与供暖 | 房屋面积、目标室内温度、室外设计温度、建筑热工等级（K）、供暖天数、日均负荷率、供回水温差、系统水容量、日补损率 |
| R2 生活热水/洗浴 | 洗浴人数、每人每次用水量、洗浴水温、进水温度、每日次数、年天数、同时使用系数、单淋浴头流量 |
| R3 家用电器与用电 | 电器清单（功率×数量，自动汇总）、同时系数、家庭年用电量、年充电量、**充电桩电价**（高于生活电价） |
| R4 燃气与价格 | 燃气类型（**城市天然气 / 液化石油气钢瓶**）、**阶梯气价** 3 档、**阶梯电价** 3 档、余电上网电价、水价 |
| R5 屋顶光伏（可选） | 屋顶面积、单位面积装机、年利用小时、自用比例、造价 |
| R6 设备与运行 | 单模块功率（默认 **12.5 kW**）、设备成本（默认 **1 万元/kW**）、发电效率 η_e、热回收效率 η_h、供热输送效率、燃气热水器效率、运行策略（按热/按电/手动）、运行上限 |
| R7 投资经济评价 | 年运维费率、寿命期、折现率、年补贴 |

**输出**：① 供暖负荷（面积+室温 → Q=K·A·ΔT）② 生活热水/洗浴（人×水量×温差）③ **补水对比**（供暖闭式循环极少 ↔ 洗浴直排全量）④ 家用电器 → 模块匹配（⌈负荷÷12.5⌉）⑤ 装置能量平衡 ⑥ **与燃气热水器年度账单对比** ⑦ 经济效益（回收期/NPV/IRR/ROI）⑧ **敏感性（气价×电价 → 回收期）** + 校验行。

**关键公式**：
- 供暖热负荷 `Q = K · A · (T_in − T_out) / 1000` (kW)；供暖耗热 `Q · 24 · 天数 · 负荷率`；闭式补水 `系统水容量 × 日补损率 × 天数`
- 洗浴耗热 `每人次 = V(L)·4.18·(T_shower − T_cw)/3600` (kWh)；直排补水 = 用水量 1:1
- 模块数 `N = ⌈计算负荷 ÷ 12.5⌉`；装机 `P = N × 12.5`
- 装置发电 `E = P · h_run`；燃气输入 `E / η_e`；回收热 `燃气输入 · η_h`
- 阶梯计价按 **月用量分档**（气、电各自的 3 档）

**口径说明（重要）**：
- 民用天然气 LHV **9.972 kWh/Nm³**（35.9 MJ/Nm³，12T）；液化石油气 LHV **12.56 kWh/kg**（45.2 MJ/kg）
- 对比基准 = 燃气热水器/壁挂炉供热 + 电网购电；装置把「余热供热」和「自发电替代购电」作为收益
- **默认参数下（外购居民阶梯气价）年节省为负**（燃气发电成本高于电网电价）——真实结论；气价越低 / 电价越高 / 设备造价越低 / 加装光伏越划算，工具给出敏感性矩阵
- 假设值（K、用水定额、同时系数、阶梯价、造价）均可调，正式报价以实测与厂家样本为准
