有什么气，就做什么样的分布式能源

不挑气源，只挑气质。我们先把气净化到重整器能接受的范围，再按用能负荷配置制氢、发电与余热回收。

沼

沼气

畜禽粪污、食品废水、秸秆、垃圾填埋、棕榈油厂 POME。

  • CH₄ 50–65%
  • 脱硫 + 脱水 + 稳压
  • 养殖场自用或并网
煤

煤层气 / 瓦斯

煤矿井下抽采瓦斯、瓦斯泵站与瓦斯电站。

  • CH₄ 30–80%
  • 浓缩 / 掺混 + 精脱硫
  • 以电为主、余热供暖
油

油田伴生气

边远井、集输站、放空与火炬气资源化。

  • CH₄ 60–90%
  • 脱重烃 + 脱水 + 稳压
  • 替代柴油机与火炬
气

城市天然气

门站、工商业园区、酒店、医院与数据中心。

  • CH₄ 90–99%
  • 调压 + 精脱硫
  • 电、热、冷三联供
系统怎么走

从气源到冷热电，五步闭合

核心装备做成撬装，现场只做接管、接电、接水与调试。氢气按需现制、机内即用，不设高压储氢。

净化稳压脱硫至 H₂S ≤ 20 ppm，脱水、过滤、稳压。
重整制氢700–850℃ 蒸汽重整，甲烷 + 水 → 氢 + CO。
变换提纯水煤气变换 + PSA，产品氢 ≥70%，CO < 10 ppm。
燃料电池PEMFC 电化学发电，无高温火焰、低噪声。
余热回收并出 40–50℃ 热水，供发酵罐、供暖或生活热水。

电和热，本来就该一起算

燃料电池发电效率 ≥40%，其余大部分以余热形式回收，综合效率 ≥85%。对养殖场、油田站场和园区来说，热往往比电更值钱。

  • 余热优先回用厌氧罐增温，破解寒区冬季产气衰减
  • 热水、蒸汽、吸收制冷按负荷梯级利用
  • 并网 / 孤岛 / 黑启动可选，适配弱电网
  • 模块化并联，按气量分期扩容

样板与场景

寒区猪场，余热回罐

黑龙江宝泉岭，常年存栏 9,000 头以上规模化猪场。粪污厌氧发酵产沼气，配置 120–150 kW 沼气重整制氢热电联产机组。

  • 年发电约 105–131 万 kWh，余热 150–250 kW
  • 余热回用发酵罐增温，最冷月需求 80–120 kW
  • 破解北方寒区沼气池冬季产气衰减 70–90% 的行业难题
  • 已获黑龙江省农业科学院推荐
